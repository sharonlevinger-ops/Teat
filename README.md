# יומן 2.0 – אפליקציה אישית לאייפון (PWA)

יומן, משימות, מסמכים וסיסמאות באפליקציה אחת, בעברית, פרטית לגמרי. כל המידע נשמר **רק באייפון שלכם** (IndexedDB). אין שרת ואין מעקב.

## מה יש באפליקציה
| לשונית | יכולות |
|---|---|
| **יומן** | תצוגה יומית (06:00–23:00 עם קו "עכשיו") ותצוגה שבועית א׳–ש׳ (מוצגת אוטומטית כשמסובבים את האייפון לרוחב). חגים, ערבי חג, חול המועד וימי זיכרון בישראל, ותאריך עברי. הערות חופשיות, משימות מקוננות ומסמכים מצורפים לכל אירוע |
| **משימות** | דחופות / להיום / פתוחות. משימות שנוצרו מאירוע מקבלות תג "יומן" ומסונכרנות בשני הכיוונים |
| **כתובות** | חוגים, משפחה, הורים של חברים, רופאים ועוד, לפי קטגוריות. ניווט בהקשה (Waze / מפות Apple / Google), חיוג, הערות (קוד לשער, חניה). כל אירוע ביומן יכול לקבל כתובת, חדשה או מהשמורות |
| **מסמכים** | תיקיות (חוזי דירה, ביטוחי רכבים, רישיונות, טיפולים וטסט, קבלות וזיכויים) וגם תיקיות משלכם. מצלמה, גלריה או PDF. דחיסה אוטומטית (1600px, JPEG 0.78), תאריכי תפוגה (כתום 14 יום לפני, אדום אחרי), וצפייה במסך מלא עם זום לסריקת ברקוד בקופה |
| **סיסמאות** | כספת מוצפנת AES-256-GCM. דורשת Face ID או קוד בכל כניסה. הסתרה, העתקה בהקשה (הלוח מתנקה אחרי 30 שניות), חיפוש, ותבניות "רכב א׳ / רכב ב׳" |
| **🎙️ הקלטה** | כפתור צף. דיבור בעברית (he-IL) עובר לפענוח חכם, למשל: *"מחר בחמש פגישה עם חשמלאי ולאחר מכן לקנות חלב"*, ונשמר בהקשה אחת |

**אבטחה:** היומן נפתח ישירות, בלי קוד. רק כספת הסיסמאות (וגם הגיבוי) מוגנים בקוד 4–6 ספרות שנבחר בכניסה הראשונה לכספת (גיבוב PBKDF2-SHA256), או ב-Face ID. אחרי 5 ניסיונות שגויים יש השהיה.
**גיבוי:** הגדרות ← "ייצוא גיבוי מוצפן" ← "שמירה בקבצים" ← iCloud Drive. במכשיר חדש: "שחזור מגיבוי" עם אותו הקוד.

## העלאה לאוויר תוך דקה (חובה HTTPS בשביל Face ID ו-Service Worker)
אין שלב בנייה: מעלים את התיקייה כמו שהיא.

**Netlify (הכי מהיר):** נכנסים ל-https://app.netlify.com/drop וגוררים את תיקיית הפרויקט. מקבלים כתובת `https://xxxx.netlify.app`.

**Vercel:** `npx vercel --prod` מתוך תיקיית הפרויקט (Framework: Other, בלי פקודת build).

**GitHub Pages:** בריפו: Settings ← Pages ← Deploy from branch ← בוחרים את הענף ואת `/ (root)`.

## התקנה באייפון
1. פותחים את הכתובת ב-**Safari**.
2. כפתור השיתוף ⬆️ ← **"הוספה למסך הבית"** ← הוספה.
3. פותחים מהאייקון "יומן 2.0" (מסך מלא, בלי סרגלי דפדפן). את קוד הכספת בוחרים בכניסה הראשונה ללשונית "סיסמאות".

> טיפ: אם ההקלטה הקולית לא זמינה במצב אפליקציה, אפשר להשתמש במיקרופון של המקלדת. הטקסט עובר את אותו הפענוח החכם.

## פיתוח
```bash
npm run serve   # שרת מקומי בפורט 5173
npm test        # בדיקות למפענח העברית
npm run check   # בדיקת תחביר לכל הקבצים
```
מבנה: `index.html`, `manifest.json`, `sw.js`, `css/app.css`, `js/` (`parser.js` מפענח עברית, `holidays.js` חגים, `crypto.js` ו-`auth.js` הצפנה ואימות, `db.js` IndexedDB, `views/` המסכים).
הלוח השבועי הקודם נשמר בקובץ `weekly-board.html`.
