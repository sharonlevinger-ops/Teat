# קנאביס ביקורות

אתר בעברית לחיפוש זני קנאביס, פענוח תפריטי PDF של בתי מרקחת (תפרחות בלבד, עם קטגוריה כמו T22/C4 וסוג),
וכרטיס זן שמרכז מידע וביקורות ממקורות ישראליים – **רק נתונים אמיתיים עם קישור למקור**.

## הפעלה

דרוש Node.js 22.5 ומעלה (משתמשים ב-SQLite המובנה ב-Node, בלי התקנות native).

```bash
npm run setup      # התקנת תלויות לשרת ולאתר
npm run build      # בניית האתר (web/dist)
npm start          # השרת + האתר על http://localhost:3001
```

פיתוח עם רענון אוטומטי: `npm run dev` (האתר על http://localhost:5173, השרת על 3001).

| פקודה | מה היא עושה |
|---|---|
| `npm test` | כל הבדיקות (פענוח PDF, נרמול, scrapers, API) |
| `npm run parse-menu -- menu.pdf` | פענוח PDF מהטרמינל והדפסת JSON |
| `npm run check-sources` | בדיקת robots.txt ותנאי שימוש לכל מקור, בלי לאסוף |
| `npm run scrape` | איסוף מהמקורות המאושרים, לזנים שמופיעים בתפריטים שהועלו |
| `npm run save-fixture -- <site> <url>` | שמירת דף אמיתי לבדיקות (מכבד robots.txt) |

## מבנה

```
server/
  index.js, app.js       שרת Express ו-API
  db.sql, db.js          סכמה ושאילתות (node:sqlite)
  normalize.js           נרמול שמות (בלי מיני/סמול), סוג, אחוזים, ציונים, שושלת
  menu/parsePdf.js       פענוח תפריט PDF לפי מיקומי x/y (pdf.js)
  scrapers/<site>.js     scraper לכל אתר: cannapedia, cannabisplus, cannabismonitor, hydroshop, rollup
  scrapers/base.js       robots.txt, שער תנאי שימוש, הגבלת קצב, cache
  scrapers/extract.js    חילוץ גנרי: JSON-LD ותוויות טקסט
  ingest.js, scrape.js   שמירה למסד עם אימות הצלבה, והרצת האיסוף
  sources.json           הגדרות המקורות (כתובות, תנאי שימוש)
  test/                  בדיקות + fixtures
web/                     React + Vite, RTL
```

## כללי הנתונים

- **אין נתון בלי מקור.** כל עובדה על זן נשמרת בשורה נפרדת ב-`strain_facts` עם `source_url` ו-`fetched_at`.
  שדה שלא נמצא נשמר `NULL` ומוצג "לא זמין".
- **אימות הצלבה.** לפני שמירה, הערך מושווה לערכים של מקורות אחרים. סתירה (למשל סאטיבה מול אינדיקה)
  מסמנת את שני הערכים `conflict`, ושניהם מוצגים בכרטיס עם המקור.
- **ביקורות.** נשמרים קטעים של עד 200 תווים עם קישור לביקורת המלאה. חיובית או שלילית נקבע רק לפי ציון
  שהמקור נתן (4 ומעלה / 2 ומטה) או לפי אזור "יתרונות/חסרונות" מפורש באתר, ולא לפי ניחוש של הטקסט.
- **שמות.** זן = שם מקומי + יצרן. שם גלובלי נשמר רק כשמקור קובע אותו במפורש ("ידוע גם בשם" וכד').
  "מיני" ו"סמול" הם גודל אריזה, ולכן "מיני חמניה צהובה" ו"חמניה צהובה" של אותו יצרן הם אותו זן.
  אותו שם אצל יצרן אחר מוצג בנפרד, עם הערה "לא בהכרח אותו זן".
- **איסוף אחראי.** מקור נאסף רק אם: (1) הוגדרה לו כתובת ב-`sources.json`, (2) robots.txt מתיר,
  (3) `tos_status` הוא `"allowed"` אחרי שאדם קרא את תנאי השימוש. בנוסף, ההשהיה בין בקשות לאותו אתר
  היא לפחות 4 שניות (או crawl-delay אם גדול יותר), ודפים נשמרים ב-cache ל-7 ימים.

## הפעלת מקור

1. מלאו ב-`server/sources.json`: `base_url`, `tos_url`, `search_url_template` (עם `{q}`), ואם צריך `strain_url_pattern`.
2. קראו את תנאי השימוש של האתר. אם הם מתירים, שנו את `tos_status` ל-`"allowed"`; אם הם אוסרים, ל-`"forbidden"`.
3. הריצו `npm run check-sources` וודאו שהמקור מקבל `ok`.
4. שמרו דף זן לדוגמה: `npm run save-fixture -- cannapedia <url>`. אם החילוץ הגנרי לא מספיק,
   הוסיפו סלקטורים בקובץ `server/scrapers/<site>.js`, ושמרו לצד הדף `.expected.json` שבדקתם.
5. הריצו `npm run scrape`.

## פענוח PDF

הטקסט שמתקבל מ-PDF בעברית מגיע בסדר מעורבב, ולכן הפענוח עובד לפי מיקום:
- עמודות מזוהות לפי מיקום סימן ₪ (תמיד בקצה השמאלי של שורה), ונקראות מימין לשמאל.
- פריטים בגובה y דומה בתוך עמודה = שורה. בשורה: גופן בינוני = שם, גופן קטן = יצרן, המספר שליד ₪ = מחיר בפועל.
- כותרת קטגוריה (T22/C4) ושורת סוג (סאטיבה/אינדיקה/הייבריד) "זורמות" לעמודה ולעמוד הבאים.
- נקראים רק עמודים שכותרתם "תפרחות"; עמודי שמנים וגליליות מדולגים. טקסט מוסתר מתחת לכותרת התחתונה
  ("עמוד X מתוך Y") מתעלמים ממנו.

התפריט לדוגמה (`server/test/fixtures/menus/medica-2026-09-14.pdf`) מפוענח ל-192 תפרחות, והתוצאה אומתה מול התמונה.
