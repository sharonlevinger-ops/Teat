# Forest Pinball Saga 🍄

משחק פינבול תלת-ממדי לאייפון (לאורך), עם מגדל פטריות, מכשף לבן, מולטי-בול ושלושה פרקי סיפור.
רץ כאפליקציית רשת מלאה (PWA): מתקינים מ-Safari למסך הבית, נפתח במסך מלא ועובד גם בלי אינטרנט.

## איך משחקים
| פעולה | שליטה |
|---|---|
| פליפר שמאלי / ימני | נגיעה בחצי השמאלי / הימני של המסך (מולטי-טאץ') |
| שיגור | לחיצה ארוכה בפינה הימנית-תחתונה ושחרור. הכוח עולה כל עוד מחזיקים |
| Skill Shot | לשחרר כשהטבעת הירוקה סביב הפטריה העליונה והכיתוב **NOW!** נדלקים: הכדור נשלח אל הפטריה, ‎+5,000 |
| הפסקה / הגדרות | הכפתורים העגולים בפינות העליונות |
| מקלדת (מחשב) | ‏Z / ← פליפר שמאלי, ‏M / → פליפר ימני, רווח לשיגור, P להפסקה |

**RUSH COMBO:** פגיעה ב-6 האלמנטים (3 פטריות, 2 קריסטלים, שיקוי) בכל סדר: ‏30 שניות של ‎×2.
**WIZARD'S TOWER MULTIBALL:** שלוש פגיעות במכשף פותחות את דלת המגדל ל-20 שניות. כניסה לדלת: ‎+15,000 ו-4 כדורים ל-60 שניות. פגיעה בדלת במהלך המולטי-בול: Super Jackpot ‏25,000.
**Combo Chain:** פגיעות ברמפות, בלופים ובאלמנטים בהפרש של עד 3 שניות זו מזו בונות קומבו x2, x3 ועד x9. כל פגיעה בשרשרת מוסיפה בונוס של ‎250 × (רמה − 1).
**Kickback:** דולק בתחילת כל כדור ומציל כדור אחד מהנתיב השמאלי. פגיעה בשיקוי מדליקה אותו מחדש.
**פרקים:** ‏15,000 נקודות פותחות את "CHAPTER 2: NIGHT'S MAGIC" (‏×1.5), ‏40,000 את "CHAPTER 3: DRAGON'S GATE" (‏×2.0).

## התקנה באייפון
1. מעלים את הריפו כמו שהוא (Netlify כבר מוגדר, אין שלב בנייה). המשחק נמצא בכתובת `/pinball/`.
2. פותחים את הכתובת ב-Safari, ‏⬆️ ← "הוספה למסך הבית".
3. אם המתג הצדדי של האייפון על "שקט", Safari משתיק את הסאונד של המשחק.

## ארכיטקטורה
```
pinball/js/
  core/      סימולציה טהורה (בלי DOM, רצה גם ב-Node לבדיקות)
    config.js    ניקוד, זמנים, פרקים, קבועי פיזיקה
    table.js     פריסת השולחן ("מגדל הפטריות המעודכן"): קירות, פטריות, חיישנים, רמפות
    physics.js   פיזיקה דו-ממדית עם Continuous Collision Detection
    rules.js     חוקי המשחק: ניקוד, מצבים, פרקים, מולטי-בול. טיימרים בטיקים שלמים
    sim.js       מחבר פיזיקה וחוקים, Object Pool לכדורים, משגר, רמפות, חילוץ כדור תקוע
    events.js    EventBus: הערוץ היחיד מהלוגיקה אל התצוגה
  render/    Three.js: סצנה, טקסטורות פרוצדורליות (צבע + זוהר + תבליט), צללים, Bloom, תאורת פרקים, חלקיקים (Pool)
  audio/     Web Audio: כל האפקטים והמוזיקה מסונתזים בזמן אמת (אין קובצי סאונד)
  ui/        HUD ו-Input (מגע + מקלדת)
```
- **הפרדה מלאה:** הלוגיקה לא יודעת על גרפיקה. התצוגה, הסאונד וה-HUD רק מאזינים לאירועים וקוראים מצב.
- **צעד קבוע:** הסימולציה רצה ב-120Hz קבוע, והרינדור עושה אינטרפולציה. לכן 30 שניות הן בדיוק 3,600 טיקים.
- **מניעת חדירה (CCD):** כל צעד מחולק לתת-צעדים כך שאף כדור וקצה פליפר לא זזים יותר מ-‎0.3 מרדיוס הכדור בין בדיקות.
- **בלי GC בזמן משחק:** 4 כדורים, ‏700 חלקיקים ו-10 חלוניות ניקוד נוצרים מראש. בלולאת הפיזיקה אין הקצאות.
- **גרפיקה:** רצפת יער מצוירת (טחב, אבני מרצפת, שורשים, שרכים, פרחים זוהרים, רונות) עם מפת תבליט, צללים אמיתיים מאור ראשי, Point Lights צבעוניים סביב הפטריות, המגדל והבריכה, ו-Bloom לזוהר הקסום. מותאם ל-iPhone 13 Pro Max (‏428×926, Safe Area).
- **מובייל:** גיאומטריה סטטית ממוזגת (גיאומטריה ממוזגת, InstancedMesh לנורות ולאבנים), ‏shaders קלים, ו-HUD שמתעדכן רק כשערך משתנה. איכות אדפטיבית: אם הקצב יורד, יורדת קודם הרזולוציה ואחר כך ה-Bloom, וחוזרים כשיש מרווח. במצב Battery saver אין Bloom ואין צללים.
